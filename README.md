# super_hero_app

Una aplicación Flutter para buscar y explorar información detallada sobre superhéroes.

## Características

- **Búsqueda en tiempo real**: Encuentra superhéroes mientras escribes
- **Listado visual**: Cards con gradientes y imágenes de los superhéroes
- **Vista detallada**: Información completa incluyendo:
  - Imagen en alta resolución
  - Nombre real del superhéroe
  - Estadísticas de poder visualizadas con barras de colores (Power, Intelligence, Strength, Speed, Durability, Combat)
- **Interfaz responsive**: Diseño adaptable con animaciones fluidas
- **Caché de imágenes**: Optimización con `cached_network_image`

## Tecnologías

- **Flutter** - Framework de UI multiplataforma
- **HTTP** - Consumo de API REST
- **Dart** - Lenguaje
- **API**: [SuperHero API](https://akabab.github.io/superhero-api/)

## Instalación
```bash
# Clonar el repositorio
git clone [tu-repositorio]

# Instalar dependencias
flutter pub get

# Ejecutar la aplicación
flutter run
```
